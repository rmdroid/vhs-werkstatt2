# Praxis-Werkstatt KI: Analysieren

VHS-Tageskurs (9–14 Uhr) für Verwaltungsmitarbeitende. Schwerpunkt: strukturierte Auswertung von Texten und Tabellen mit **ChatGPT**, **Mistral Le Chat** und **Claude** (nur kostenlose Accounts), inklusive Plausibilitätscheck und Entscheidungsvorlage.

## Inhalte dieses Repos

| Pfad | Zweck |
|---|---|
| `index.html` | Kurs-Startseite (GitHub Pages) |
| `kurs-hero.jpg` | Hero-Illustration auf der Startseite |
| `daten/buergeranliegen.csv` / `.xlsx` | Übungsdaten Bürgeranliegen Musterstadt 2025 |
| `daten/aufwaermen_mini.csv` | Mini-Tabelle mit Rechenfehler (Station 1) |
| `daten/stellungnahme_a.docx` / `_b.docx` | Zwei Stellungnahmen zum Parkplatz-Sachverhalt |
| `daten/ki_ergebnis_fehlerbingo.docx` | KI-Ergebnis mit eingebauten Fehlern (Bingo) |

Markdown-Quellen der DOCX liegen parallel als `.md` in `daten/`.

## Hinweise

- Alle Daten sind **fiktiv** (Stadt Musterstadt). Keine echten Personen- oder Ortsdaten.
- Miro-Board- und Teams-Links auf der Startseite sind Platzhalter und werden kurz vor dem Kurs gesetzt.
